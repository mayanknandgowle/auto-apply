# Changelog

## 0.2.0 — 29 October 2026 — internal alpha

- Added structured career records, precise experience/pay helpers, contact-import rollback and source-deletion provenance.
- Added job-scoped answer memory, reviewed evidence scoring and readability checks.
- Added passphrase-protected saved profiles, idle lock, schema migration, encrypted backup preview/restore, passphrase change and corruption recovery.
- Added individual resume change review, local PDF/DOCX generation, exact reparse verification, PDF previews, original/derivative lineage and explicit version selection.
- Added explicit native resume attachment with hash/type checks, durable attempts and honest processing status.
- Added OpenAI Responses and custom compatible-provider transports beside Gemini; keys remain destination-bound and session-only.
- Added preparation/user-reported receipts, deletion/retention and export.
- Expanded domain, storage, provider, document, attachment and accessibility regression coverage; updated pinned notices and local font assets.
- Automated navigation/submission and named ATS/direct-profile-import validation remain unavailable. Live providers, complete document accessibility and production release gates remain open.


## 0.1.0 — 29 October 2026 — internal alpha

- Added standalone WXT/React/TypeScript Chrome/Edge MV3 builds.
- Added encrypted session-only profile, original resume and application checkpoints.
- Added strict trusted-UI commands, one-action field driver, durable intents and revision checks.
- Added contact profile, local PDF/DOCX text intake, reviewable imports and career evidence.
- Added generic verified empty-field filling, dynamic rescan, per-page decisions, pause and conditional undo.
- Added optional fixed-origin Gemini BYOK adapter, explicit sharing preview and reviewed drafts.
- Added manual multipage fixture, browser security/recovery tests, unit tests and accessibility audit.
- No automatic navigation, upload or submission; no named ATS support claims; live provider unverified.
