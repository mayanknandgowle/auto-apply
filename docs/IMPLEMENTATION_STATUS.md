Version 0.2.1 is an internal-alpha coverage and recovery slice. Milestones 0–3 remain partially complete. The detailed requirement dispositions, evidence and external gates are in [the continuation checklist](CONTINUATION_CHECKLIST.md).

## Implemented in this continuation

- Reviewed native radio/checkbox choices, disabled/validation feedback, and native fields inside open shadow roots. Existing values, legal terms and unsupported controls stay protected.
- A bundled, locally disableable Lever hosted-form interpreter based on one read-only public observation, with a sanitized fixture. This does not establish live filling/upload support or other tenant compatibility.
- Explicit same-tab/same-origin step continuation retains the application journal and upload attempts. Reload cannot silently authorize retries. Worker reconnect gates prevent premature filling.
- Persistent defer/unknown decisions, exact option display, context/requisition-bound answer reuse and explicit sensitive-answer journal choice. Receipts omit sensitive disclosures.
- Separate job sources, quoted proposed fields, uncertainty, capture metadata, classification and conflict review. Pasted text stays user-provided.
- Reviewed labeled employment/education imports, duplicate/conflict matching, explicit keep/replace/separate choices, source excerpts and conditional rollback. Added certifications, languages, preferences and availability to the profile.
- Grounded evidence/formatting proposals and visible gaps; stronger whole-number and cited-new-word checks for derivative edits.
- Provider configuration rechecked after asynchronous permission verification; no retries, new destinations or live provider costs.
- Browser regression fixes, new failure/reload/adapter/accessibility scenarios and ZIP-to-build integrity checks in CI.
